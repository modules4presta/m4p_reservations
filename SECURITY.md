# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately:

- GitHub: **Security → Report a vulnerability** (private advisory), or
- e-mail: **contact@modules4presta.io**

Include the module version, the PrestaShop and PHP versions and the steps to reproduce. We confirm
reports within 5 working days and agree a disclosure date with you once a fix is ready.

## Supported versions

The latest released version is supported. Older versions get fixes only when the issue is critical
and the upgrade path is not straightforward.
